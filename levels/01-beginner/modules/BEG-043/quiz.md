# BEG-043 · Graph basics — Quiz

Outcomes: O1 adjacency list · O2 BFS and DFS · O3 shortest path · O4 graph problems in systems.

**Q01 (O1)** A graph is made of: A. Rows and columns B. Nodes and edges C. Keys and buckets D. Parents and root only
**Q02 (O1)** An adjacency list stores for each node: A. Its neighbors B. Its depth C. Its value only D. A sorted copy of the graph
**Q03 (O1)** A one-way street is best modeled as a(n): A. Undirected edge B. Cycle C. Directed edge D. Leaf
**Q04 (O2)** BFS uses a: A. Stack B. Queue C. Heap D. Matrix
**Q05 (O2)** Without a visited set, BFS on a graph with a cycle may: A. Run faster B. Run forever C. Sort the nodes D. Find a shorter path
**Q06 (O2)** Recursive DFS relies on the: A. Call stack B. Queue C. Heap memory only D. Visited map only
**Q07 (O3)** In an unweighted graph, the shortest path (fewest edges) is found by: A. DFS B. Sorting C. BFS D. Hashing
**Q08 (O3)** BFS time for `V` nodes and `E` edges with an adjacency list: A. O(V + E) B. O(V²) C. O(1) D. O(E²)
**Q09 (O4)** "Library A needs B, B needs A" is a: A. Tree B. Cycle C. Queue D. Heap
**Q10 (O4)** Which is a graph problem? A. Sorting a list of ages B. Finding the fewest metro stops between stations C. Adding two numbers D. Reversing a String

## Answers
Q01 B · Q02 A · Q03 C · Q04 B · Q05 B · Q06 A · Q07 C · Q08 A · Q09 B · Q10 B
