# BEG-001 · Understanding computers — Quiz

10 questions. Pass mark per `assessment/framework.md`. Each question lists the outcome it checks (O1–O4). Answers are at the end.

**BEG-001-Q01 (O1)** Which part of a computer executes instructions?
A. RAM  B. CPU  C. SSD  D. Monitor

**BEG-001-Q02 (O1)** A microphone is an example of:
A. Input device  B. Output device  C. Storage  D. Processor

**BEG-001-Q03 (O1)** Which sequence matches the kitchen analogy: chef, countertop, pantry?
A. RAM, CPU, SSD  B. CPU, RAM, SSD  C. SSD, RAM, CPU  D. CPU, SSD, RAM

**BEG-001-Q04 (O2)** You edit a document and the computer loses power before you save. Why is your work gone?
A. The SSD is full  B. The CPU overheated  C. The document was only in RAM, which loses data without power  D. The OS deleted it on purpose

**BEG-001-Q05 (O2)** Which statement is true?
A. RAM keeps data after power-off; SSD does not  B. SSD keeps data after power-off; RAM does not  C. Both lose data  D. Both keep data

**BEG-001-Q06 (O3)** How many bits are in one byte?
A. 2  B. 4  C. 8  D. 16

**BEG-001-Q07 (O3)** What is binary `1010` in decimal?
A. 5  B. 8  C. 10  D. 12

**BEG-001-Q08 (O3)** What is decimal 6 in binary?
A. `101`  B. `110`  C. `011`  D. `1000`

**BEG-001-Q09 (O4)** Which best describes a *process*?
A. A file on disk containing a program  B. A running instance of a program, with its own PID  C. A piece of hardware  D. A type of operating system

**BEG-001-Q10 (O4)** Which of these is NOT a main job of the operating system?
A. Share CPU and RAM between programs  B. Manage hardware access  C. Provide services such as file access  D. Write the application's business logic

## Answers

| Q | Answer | Why |
| --- | --- | --- |
| Q01 | B | The CPU is the chef that runs instructions. |
| Q02 | A | A microphone sends sound into the computer. |
| Q03 | B | CPU = chef, RAM = countertop, SSD = pantry. |
| Q04 | C | Unsaved work lives in volatile RAM. |
| Q05 | B | SSD is non-volatile; RAM is volatile. |
| Q06 | C | A byte is 8 bits. |
| Q07 | C | 8 + 0 + 2 + 0 = 10. |
| Q08 | B | 4 + 2 = 6 → `110`. |
| Q09 | B | Application = file; process = running instance. |
| Q10 | D | Business logic is written by the application's developers. |

## Practical part (assessment)

Convert five numbers to and from binary, chosen from this bank: `BEG-001-EX04` and `BEG-001-EX05` values, plus 7, 14, 25, `11001`, `1000`, `10110`. Pass: at least 4 of 5 correct with working shown.
