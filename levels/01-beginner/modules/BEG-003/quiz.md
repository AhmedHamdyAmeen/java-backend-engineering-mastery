# BEG-003 · The internet — Quiz

Outcomes: O1 internet vs web · O2 URL to page · O3 nslookup · O4 HTTPS.

**Q01 (O1)** The web is: A. The same as the internet B. One service that runs on the internet C. A kind of cable D. A browser
**Q02 (O1)** Which is NOT the web? A. A news site B. Email between two mail servers C. An online shop page D. A blog
**Q03 (O2)** What turns a domain name into an IP address? A. HTTP B. DNS C. CPU D. RAM
**Q04 (O2)** In "client and server", the browser is the: A. Server B. Client C. Router D. Database
**Q05 (O2)** HTTP status 404 means: A. Success B. Not found C. Server crashed D. Redirect
**Q06 (O2)** A port is best compared to: A. A street name B. A door number on a building C. A city D. A postman
**Q07 (O3)** The command to look up a domain's IP is: A. `ping` only B. `nslookup` C. `cd` D. `javac`
**Q08 (O3)** A domain is: A. A server B. A name that points to one or more servers C. A cable D. A port
**Q09 (O4)** HTTPS adds: A. Faster speed B. Encryption and server identity C. A new domain D. More ports
**Q10 (O4)** HTTPS does NOT: A. Encrypt content B. Hide which site you visit C. Verify the site's identity D. Protect data in transit

## Answers
Q01 B · Q02 B · Q03 B · Q04 B · Q05 B · Q06 B · Q07 B · Q08 B · Q09 B · Q10 B

Draw and narrate the URL-to-page sequence diagram: browser, DNS, server, with each step labelled. Pass: all five steps in order.
