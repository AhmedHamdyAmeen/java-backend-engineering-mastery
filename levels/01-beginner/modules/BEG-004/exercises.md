# BEG-004 · Introduction to engineering — Exercises and lab

## Lab
### BEG-004-LAB1 · Read job posts
**Outcomes:** 1, 2, 3 · **Time:** ~1 h
Collect three real junior backend job posts. List the required skills and map each to a module in this curriculum (see `catalog/INDEX.md`).
**Acceptance:** a mapping table with at least 15 skills.

## Exercises
| ID | Outcome | Task |
| --- | --- | --- |
| BEG-004-EX01 | 1 | List four tasks an engineer does besides writing code. |
| BEG-004-EX02 | 1 | Why is readable code more valuable than clever code? One sentence. |
| BEG-004-EX03 | 2 | Match each role to its job: frontend, backend, QA, DevOps, SRE, architect. |
| BEG-004-EX04 | 2 | Who hands work to whom when a feature is released? Draw the hand-offs. |
| BEG-004-EX05 | 3 | Name the eight levels of this curriculum in order. |
| BEG-004-EX06 | 3 | Pick the level you want to reach and write two sentences on what it adds. |

## Solutions
- **EX01** Design, testing, code review, fixing production issues, talking to teammates.
- **EX02** Code is read far more often than written, so teammates must be able to understand it.
- **EX03** Frontend: what users see. Backend: hidden service and data. QA: finds bugs. DevOps: automates build and release. SRE: keeps production reliable. Architect: how big pieces fit.
- **EX04** Design → code → review → test → release → operate.
- **EX05** Beginner, Junior, Mid, Senior C, Senior B, Senior A, Staff, Solution Architect.
- **EX06** Any reasoned answer that matches the level descriptions in the README.
