# BEG-015 · Arrays and strings — Quiz

Outcomes: O1 arrays · O2 String methods · O3 immutability and StringBuilder · O4 valid indices.

**Q01 (O1)** The first index of an array is: A. 1 B. 0 C. -1 D. `length`
**Q02 (O1)** `new int[5]` creates an array whose elements start as: A. null B. 0 C. 1 D. Random
**Q03 (O1)** `grid[2][3]` in a 2D array means: A. Column 2, row 3 B. Row 2, column 3 C. Two cells D. Sum of 2 and 3
**Q04 (O2)** To compare two Strings' text, use: A. `==` B. `equals` C. `=` D. `compare()` only on numbers
**Q05 (O2)** `"hello".substring(1, 3)` is: A. "el" B. "ell" C. "hel" D. "he"
**Q06 (O2)** `indexOf` returns what when the text is missing? A. 0 B. -1 C. null D. An exception
**Q07 (O3)** Strings are immutable. So `s.toUpperCase();` alone: A. Changes `s` B. Returns a new String that is ignored C. Causes an error D. Deletes `s`
**Q08 (O3)** For repeated concatenation in a loop, use: A. `+=` B. `StringBuilder` C. `==` D. `split`
**Q09 (O4)** For an array of length 5, the last valid index is: A. 5 B. 4 C. 6 D. 0
**Q10 (O4)** `arr[arr.length]` causes: A. The last element B. `ArrayIndexOutOfBoundsException` C. 0 D. A compile error
