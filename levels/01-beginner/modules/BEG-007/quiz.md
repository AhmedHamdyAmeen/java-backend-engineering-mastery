# BEG-007 · How code runs — Quiz

Outcomes: O1 source/bytecode/machine code · O2 JDK/JRE/JVM · O3 compile and run · O4 error kinds.

**Q01 (O1)** The CPU directly runs: A. Source code B. Bytecode C. Machine code D. Comments
**Q02 (O1)** `javac` turns `.java` into: A. Machine code B. A `.class` file with bytecode C. A PDF D. Text
**Q03 (O1)** A compiler translates: A. Line by line as the program runs B. The program before it runs C. Only comments D. Nothing
**Q04 (O2)** Which runs bytecode? A. JVM B. `javac` C. Notepad D. The browser
**Q05 (O2)** Which includes the compiler? A. JRE B. JDK C. JVM D. A `.class` file
**Q06 (O2)** A developer should install the: A. JRE B. JDK C. JVM only D. Nothing
**Q07 (O3)** To run class `Hello` you type: A. `java Hello` B. `java Hello.class` C. `javac Hello` D. `run Hello`
**Q08 (O3)** `javac Hello.java` requires: A. File name matching the public class name B. Any file name C. A `.txt` extension D. No JDK
**Q09 (O4)** A missing semicolon is a: A. Runtime error B. Compile-time error C. Hardware error D. Network error
**Q10 (O4)** Dividing by zero while running is a: A. Compile-time error B. Runtime error C. Typo D. Warning only

## Answers
Q01 C · Q02 B · Q03 B · Q04 A · Q05 B · Q06 B · Q07 A · Q08 A · Q09 B · Q10 B

## Practical part
Explain the compile/run pipeline aloud while demonstrating it: write, `javac`, show `.class`, `java`. Pass: all four steps and the name of each file involved.
