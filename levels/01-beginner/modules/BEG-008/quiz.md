# BEG-008 · First Java program — Quiz

Outcomes: O1 program parts · O2 printing · O3 comments · O4 compiler errors.

**Q01 (O1)** Where does a Java program start? A. The first line of the file B. The `main` method C. The last method D. The comment
**Q02 (O1)** The correct `main` line is: A. `public static void main(String[] args)` B. `public void main()` C. `static main(String args)` D. `main(String[] args)`
**Q03 (O1)** `Hello.java` must contain: A. Any class name B. A public class named `Hello` C. Only comments D. No class
**Q04 (O1)** Java is: A. Case sensitive B. Case insensitive C. Only lowercase D. Only uppercase
**Q05 (O2)** `System.out.println("A"); System.out.println("B");` prints: A. `AB` on one line B. `A` and `B` on two lines C. Nothing D. An error
**Q06 (O2)** `"Age: " + 30` produces: A. `Age: 30` B. `Age: + 30` C. An error D. `30`
**Q07 (O3)** Which is a Javadoc comment? A. `// hi` B. `/* hi */` C. `/** hi */` D. `# hi`
**Q08 (O3)** A good comment explains: A. What each line does B. Why the code does something C. Nothing D. The compiler
**Q09 (O4)** `';' expected` usually means: A. A missing semicolon B. A missing brace C. A wrong class name D. A slow PC
**Q10 (O4)** `cannot find symbol` for `system.out` means: A. Wrong case: use `System` B. Missing semicolon C. Missing JDK D. Wrong file name

## Answers
Q01 B · Q02 A · Q03 B · Q04 A · Q05 B · Q06 A · Q07 C · Q08 B · Q09 A · Q10 A
