# BEG-042 · Trees — Quiz

Outcomes: O1 BST · O2 traversals · O3 balance · O4 heaps and `PriorityQueue`.

**Q01 (O1)** In a BST, values smaller than a node are found in its: A. Right subtree B. Parent C. Left subtree D. Root only
**Q02 (O1)** A node with no children is a: A. Root B. Leaf C. Parent D. Subtree
**Q03 (O1)** Recursive BST code should first check: A. The height B. The size C. That the node is `null` D. The sorted order
**Q04 (O2)** In-order traversal of a BST gives: A. Insertion order B. Reverse order C. Random order D. Sorted order
**Q05 (O2)** Pre-order visits: A. Left, node, right B. Node, left, right C. Left, right, node D. Row by row
**Q06 (O2)** Level-order traversal uses a: A. Queue B. Stack C. Set D. Map
**Q07 (O3)** Inserting 1, 2, 3, 4, 5 in order into a plain BST makes search: A. O(log n) B. O(1) C. O(n) D. O(n log n)
**Q08 (O3)** Which JDK class uses a self-balancing tree? A. `ArrayList` B. `TreeMap` C. `HashMap` D. `ArrayDeque`
**Q09 (O4)** The root of a min-heap is: A. The largest item B. The median C. The newest item D. The smallest item
**Q10 (O4)** A default `PriorityQueue<Integer>` `poll()` returns the: A. Last added B. Largest C. Smallest D. First added

## Answers
Q01 C · Q02 B · Q03 C · Q04 D · Q05 B · Q06 A · Q07 C · Q08 B · Q09 D · Q10 C
