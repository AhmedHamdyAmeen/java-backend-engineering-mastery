# BEG-046 · Version control — Quiz

Outcomes: O1 init, stage, commit · O2 inspect history · O3 branch and merge · O4 `.gitignore`.

**Q01 (O1)** Which command turns a folder into a Git repository? A. `git init` B. `git start` C. `git new` D. `git commit`
**Q02 (O1)** Staging means: A. Saving to GitHub B. Choosing changes for the next commit C. Deleting files D. Creating a branch
**Q03 (O1)** Which message is best? A. "fix" B. "changes" C. "update" D. "Fix negative balance after withdraw"
**Q04 (O2)** Which command lists past commits? A. `git status` B. `git log` C. `git diff` D. `git add`
**Q05 (O2)** Which shows changes already staged? A. `git diff --staged` B. `git log` C. `git init` D. `git branch`
**Q06 (O3)** Which creates and switches to a new branch? A. `git branch -d x` B. `git merge x` C. `git commit x` D. `git switch -c x`
**Q07 (O3)** A merge conflict happens when: A. A branch is too old B. Both branches changed the same lines C. The repo is empty D. You forgot `git add`
**Q08 (O3)** After fixing conflict text in a file you must: A. Delete the repo B. Run `git init` C. Remove markers, add, and commit D. Switch to main without saving
**Q09 (O4)** Which belongs in `.gitignore`? A. `Main.java` B. `target/` C. `README.md` D. `pom.xml`
**Q10 (O4)** A password was committed by mistake. Best response: A. Ignore it B. Add it to `.gitignore` only C. Rename the file D. Change the password and treat it as leaked

## Answers
Q01 A · Q02 B · Q03 D · Q04 B · Q05 A · Q06 D · Q07 B · Q08 C · Q09 B · Q10 D

## Practical part
Terminal-only Git task: init, commit, branch, conflict, merge, `.gitignore` (EX01–EX07 and the lab). Pass: at least 8 of 10 quiz questions and a clean history with the conflict resolved.
