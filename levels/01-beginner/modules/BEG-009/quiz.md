# BEG-009 · Variables and data types — Quiz (type selection)

Outcomes: O1 declare · O2 primitive vs reference · O3 naming and `final` · O4 conversion · O5 `var`.

**Q01 (O1)** Best type for a person's age: A. `String` B. `int` C. `boolean` D. `char`
**Q02 (O1)** Best type for `true`/`false`: A. `int` B. `String` C. `boolean` D. `double`
**Q03 (O1)** Best type for a full name: A. `char` B. `int` C. `String` D. `boolean`
**Q04 (O1)** Which type should you NOT use for money in real programs? A. `int` cents B. `double` C. Both are always fine D. `String` only
**Q05 (O2)** `String` is a: A. Primitive B. Reference type C. Number D. Keyword
**Q06 (O3)** The Java style for a variable name is: A. `Total_Price` B. `totalPrice` C. `TOTALPRICE` D. `total-price`
**Q07 (O3)** `final` on a variable means it: A. Can be changed B. Cannot be reassigned C. Is deleted D. Is a String
**Q08 (O4)** `7 / 2` in Java gives: A. 3.5 B. 3 C. 4 D. An error
**Q09 (O4)** `(int) 3.9` gives: A. 4 B. 3.9 C. 3 D. An error
**Q10 (O5)** `var x = 10;` makes `x` a(n): A. `int` B. `String` C. `double` D. Dynamic type

## Answers
Q01 B · Q02 C · Q03 C · Q04 B · Q05 B · Q06 B · Q07 B · Q08 B · Q09 C · Q10 A
