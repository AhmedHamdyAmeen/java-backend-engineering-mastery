# BEG-025 · Relationships — Quiz

Outcomes: O1 relationship types · O2 UML · O3 one-to-many in code.

**Q01 (O1)** Parts that cannot exist without the whole show: A. Dependency B. Inheritance C. Association only D. Composition
**Q02 (O1)** A class that only uses another as a method parameter has a: A. Dependency B. Composition C. Aggregation D. Inheritance
**Q03 (O1)** A Bank holding Customers who exist independently is best called: A. Dependency B. Composition C. Aggregation D. Static
**Q04 (O1)** An Account and its Transactions (deleted together) is: A. Aggregation B. Composition C. Dependency D. Interface
**Q05 (O2)** A filled diamond in UML means: A. Composition B. Aggregation C. Inheritance D. Dependency
**Q06 (O2)** A dashed arrow in UML usually means: A. Association B. Composition C. Aggregation D. Dependency
**Q07 (O2)** Multiplicity `*` means: A. Exactly one B. Zero or more C. Exactly two D. None
**Q08 (O3)** A one-to-many link is implemented with: A. A single field B. A static variable C. A collection such as `List` D. An interface only
**Q09 (O3)** A risk of bidirectional links is: A. The two sides get out of sync B. They are faster C. They need no code D. They are always private
**Q10 (O2)** A good UML class box shows: A. Every field and method B. The name and the key members only C. The full source D. Only colors

## Answers
Q01 D · Q02 A · Q03 C · Q04 B · Q05 A · Q06 D · Q07 B · Q08 C · Q09 A · Q10 B
