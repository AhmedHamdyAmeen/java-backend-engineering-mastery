# BEG-005 · Development environment — Quiz

Outcomes: O1 install JDK · O2 IntelliJ · O3 PATH · O4 extensions.

**Q01 (O1)** To compile Java you need the: A. JRE only B. JDK C. A browser D. Only an IDE
**Q02 (O1)** Which command checks the compiler? A. `java -version` B. `javac -version` C. `cd` D. `dir`
**Q03 (O2)** An IDE is: A. An editor with helpers such as error highlighting and a run button B. A kind of OS C. A compiler only D. A web server
**Q04 (O2)** Where is a program's output shown in IntelliJ? A. The Run console B. The project tree C. The menu bar D. Nowhere
**Q05 (O3)** `PATH` is: A. A list of folders searched for commands B. A file C. A browser setting D. A type of JDK
**Q06 (O3)** After editing `PATH`, you must: A. Reboot Windows only B. Open a new terminal C. Reinstall Java D. Nothing
**Q07 (O3)** "Command not found" for `java` most likely means: A. Java is too fast B. `java` is not on `PATH` C. The disk is full D. RAM is low
**Q08 (O4)** Why show file extensions? A. To see the real file type B. To make files larger C. To speed up the PC D. To hide files
**Q09 (O4)** `Hello.java.txt` is really a: A. Java file B. Text file C. Class file D. Folder
**Q10 (O3)** `JAVA_HOME` usually holds: A. The JDK location B. The user name C. The screen size D. The IP address

## Answers
Q01 B · Q02 B · Q03 A · Q04 A · Q05 A · Q06 B · Q07 B · Q08 A · Q09 B · Q10 A

## Practical part
Practical check: both version commands print, and a new project runs in the IDE. Pass: both done without help.
