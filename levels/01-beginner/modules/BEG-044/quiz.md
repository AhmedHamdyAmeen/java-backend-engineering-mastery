# BEG-044 · Algorithmic techniques — Quiz

Outcomes: O1 two pointers · O2 sliding window · O3 recursion and backtracking · O4 choosing a technique.

**Q01 (O1)** Two pointers from both ends works best on: A. Sorted data B. Any unsorted data C. Linked lists only D. Empty arrays
**Q02 (O1)** Two pointers on a pair-sum problem takes: A. O(n²) B. O(n) C. O(log n) D. O(n³)
**Q03 (O1)** In a sorted pair-sum search, if the sum is too small you: A. Move the right pointer left B. Stop C. Move the left pointer right D. Restart
**Q04 (O2)** A sliding window is a: A. Hash bucket B. Pair of sorted arrays C. Recursive call D. Range that grows and shrinks over the data
**Q05 (O2)** The length of window `[left, right]` is: A. `right - left` B. `right - left + 1` C. `right + left` D. `left - right`
**Q06 (O3)** Every recursive method needs a: A. Loop B. Base case C. Global variable D. Return type `void`
**Q07 (O3)** Missing base case usually causes: A. A faster run B. A compile error C. `StackOverflowError` D. A correct result
**Q08 (O3)** The number of subsets of a 4-item set is: A. 8 B. 4 C. 24 D. 16
**Q09 (O3)** Backtracking follows the pattern: A. Sort, split, merge B. Choose, explore, un-choose C. Hash, probe, resize D. Push, pop, peek
**Q10 (O4)** "Longest substring with no repeated characters" calls for: A. A sliding window B. A stack C. A BST D. A heap

Q01 A · Q02 B · Q03 C · Q04 D · Q05 B · Q06 B · Q07 C · Q08 D · Q09 B · Q10 A
