# BEG-016 · Problem-solving — Quiz

Outcomes: O1 understand the problem · O2 decompose and plan · O3 hand-trace · O4 edge cases.

**Q01 (O1)** The first step in solving a problem is to: A. Start coding B. Understand and restate it C. Search for code D. Test it
**Q02 (O1)** Which is NOT one of inputs, outputs, constraints? A. Input data B. Expected result C. Rules and limits D. Editor theme
**Q03 (O2)** Decomposition means: A. Deleting code B. Splitting a problem into smaller steps C. Compiling D. Renaming variables
**Q04 (O2)** Pseudocode is: A. Java with syntax errors B. Plain-language logic with code-like structure C. Machine code D. A test
**Q05 (O2)** In a flowchart a yes/no decision is drawn as a: A. Rectangle B. Diamond C. Circle only D. Triangle
**Q06 (O3)** A variable table is used to: A. Store data in a database B. Track variable values step by step C. Format output D. Compile faster
**Q07 (O3)** In hand-tracing, the bug is usually at: A. The last row B. The first row that differs from expected C. The first row always D. No row
**Q08 (O4)** Which is an edge case for "largest in an array"? A. A normal list of 5 distinct numbers B. An empty array C. A sorted list only D. A long list only
**Q09 (O4)** Testing only the happy path: A. Is enough B. Misses many bugs C. Is slower D. Is required by Java
**Q10 (O4)** Which pair are both edge cases? A. One element and all negatives B. Two normal values C. A typical list and a sorted list D. Only a large list

## Answers
Q01 B · Q02 D · Q03 B · Q04 B · Q05 B · Q06 B · Q07 B · Q08 B · Q09 B · Q10 A

## Practical part
The graded unseen problem (plan first, then code) and the three-problem lab. Pass: plan and code match, edge cases listed before coding and all handled, and quiz at least 8/10.
