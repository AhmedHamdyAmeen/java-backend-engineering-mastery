# BEG-002 · Understanding software — Quiz

Outcomes: O1 classify software · O2 program vs service · O3 lifecycle.

**Q01 (O1)** The code that runs inside a washing machine is: A. Desktop B. Web frontend C. Embedded D. Backend
**Q02 (O1)** The part of a web app that runs in your browser is the: A. Backend B. Frontend C. Database D. Firmware
**Q03 (O1)** A server that stores orders and applies business rules is: A. Backend B. Frontend C. Embedded D. A desktop app
**Q04 (O1)** Software is best described as: A. Only the screen you see B. Instructions plus data C. Only hardware D. Only games
**Q05 (O2)** A program that runs and then exits is different from a service because a service: A. Is faster B. Keeps running and waits for requests C. Has no code D. Needs no OS
**Q06 (O2)** Why does a backend "never finish"? A. It has a bug B. Users may send requests at any time C. It is slow D. It has no instructions
**Q07 (O3)** Which stage comes right after Build? A. Requirements B. Test C. Retire D. Design
**Q08 (O3)** Keeping released software running is the stage called: A. Design B. Test C. Operate D. Requirements
**Q09 (O3)** Which describes the lifecycle best? A. A straight line that stops at Release B. A loop where feedback leads to new changes C. Only coding D. Only testing
**Q10 (O1)** A website and its backend are: A. The same thing B. Different pieces that work together C. Both hardware D. Both stored in RAM

## Answers
Q01 C · Q02 B · Q03 A · Q04 B · Q05 B · Q06 B · Q07 B · Q08 C · Q09 B · Q10 B
