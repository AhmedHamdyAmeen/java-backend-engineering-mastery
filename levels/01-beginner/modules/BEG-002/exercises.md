# BEG-002 · Understanding software — Exercises and lab

## Lab
### BEG-002-LAB1 · Software around you
**Outcomes:** 1, 2 · **Time:** ~1 h
List ten pieces of software you used today. Classify each as desktop, mobile, web frontend, backend, or embedded. Mark which ones depend on a backend service.
**Acceptance:** at least eight classified correctly, and the backend-dependent ones marked.

## Exercises
| ID | Outcome | Task |
| --- | --- | --- |
| BEG-002-EX01 | 1 | Classify: a calculator app on a PC; a ride-hailing app; the firmware in a microwave; a news website; the server that stores orders. |
| BEG-002-EX02 | 1 | Name one piece of software on your phone and say what hardware it uses (camera, GPS, screen). |
| BEG-002-EX03 | 2 | Name one program that exits when done and one service that keeps running. |
| BEG-002-EX04 | 2 | Explain in two sentences why a backend "never finishes". |
| BEG-002-EX05 | 3 | Put in order: Test, Requirements, Release, Build, Design, Operate, Retire. |
| BEG-002-EX06 | 3 | A user reports a bug after release. Which stage found it and which stage starts again? |

## Solutions
- **EX01** Desktop; mobile (with a backend); embedded; web frontend; backend.
- **EX02** Any valid answer, for example a map app using GPS.
- **EX03** For example a calculator closing; a web server running continuously.
- **EX04** It waits for requests from users all day, so it must keep running to answer them.
- **EX05** Requirements, Design, Build, Test, Release, Operate, Retire.
- **EX06** Operate found it; the cycle returns to Requirements/Build to fix it.
