# BEG-013 · Loops — Quiz

Outcomes: O1 choosing a loop · O2 correct loop parts · O3 break/continue · O4 nested loops.

**Q01 (O1)** Best loop when you know the exact count: A. `while` B. `do-while` C. `for` D. `if`
**Q02 (O1)** Which loop always runs its body at least once? A. `for` B. `while` C. `do-while` D. None
**Q03 (O2)** How many times does `for (int i = 0; i < 5; i++)` run? A. 4 B. 5 C. 6 D. Forever
**Q04 (O2)** `while (x < 10) { print(x); }` with no change to `x` is: A. Fine B. An infinite loop C. A compile error D. Skipped
**Q05 (O2)** An off-by-one error often comes from mixing up: A. `int` and `long` B. `<` and `<=` C. `if` and `else` D. `print` and `println`
**Q06 (O3)** `break` inside a loop: A. Skips one iteration B. Stops the loop C. Restarts the loop D. Does nothing
**Q07 (O3)** `continue` inside a loop: A. Ends the program B. Ends the loop C. Skips to the next iteration D. Repeats the same iteration
**Q08 (O3)** In nested loops, `break` leaves: A. All loops B. Only the innermost loop C. The method D. The program
**Q09 (O4)** Outer loop 4 times, inner loop 5 times: the inner body runs A. 9 B. 20 C. 4 D. 5
**Q10 (O4)** To print a grid of rows and columns you use: A. A single `for` B. Two nested loops C. A `switch` D. Recursion only

## Answers
Q01 C · Q02 C · Q03 B · Q04 B · Q05 B · Q06 B · Q07 C · Q08 B · Q09 B · Q10 B
