# BEG-053 · API fundamentals — Quiz

Outcomes: O1 API and REST resources · O2 Postman and curl · O3 endpoint design.

**Q01 (O1)** An API is: A. A database B. A defined way for one program to use another C. A browser D. A file format
**Q02 (O1)** In REST, URLs should be mainly: A. Verbs B. Random words C. Nouns for resources D. Numbers only
**Q03 (O1)** Which URL is best? A. `/getBooks` B. `/books/get` C. `/doBooks` D. `/books`
**Q04 (O2)** In `curl`, `-H` is used for: A. A header B. A host C. Help D. A body
**Q05 (O2)** `curl -i` shows: A. Only the body B. Status and headers too C. Nothing D. Only errors
**Q06 (O2)** A Postman collection is: A. A saved set of requests B. A database C. A response D. A server
**Q07 (O2)** A 404 from a documented endpoint most likely means: A. Success B. Server crash C. Wrong path or missing item D. Slow network
**Q08 (O3)** Endpoint to create a book: A. `GET /books` B. `POST /books` C. `DELETE /books` D. `PUT /books`
**Q09 (O3)** Status for a successful create: A. 200 B. 404 C. 201 D. 500
**Q10 (O3)** Filtering by author is best done with: A. `/books/author/herbert/get` B. A new method C. A header only D. `/books?author=herbert`

## Answers
Q01 B · Q02 C · Q03 D · Q04 A · Q05 B · Q06 A · Q07 C · Q08 B · Q09 C · Q10 D

Endpoint design exercise: sketch the Library API endpoints (EX06–EX07) and export the Postman collection (lab). Pass: at least 8 of 10 quiz questions and a reviewed sketch with no verbs in URLs.
