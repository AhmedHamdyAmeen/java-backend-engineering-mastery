# BEG-056 · AI coding assistants for learners — Quiz

Outcomes: O1 how LLMs work · O2 hallucinations · O3 good questions · O4 learning with AI · O5 safe use.

**Q01 (O1)** An LLM produces text by: A. Searching the web only B. Predicting the next token repeatedly C. Running your code D. Copying a stored answer
**Q02 (O1)** A token is: A. A password B. A small piece of text or code C. A file D. A Java keyword only
**Q03 (O1)** Why can an assistant be fluent but wrong? A. It learns patterns and does not verify facts B. It is always checking the compiler C. It has no training data D. It is a database
**Q04 (O2)** A hallucination is: A. A correct but short answer B. A confident but invented or false answer C. A compile error D. A slow answer
**Q05 (O2)** The best way to check a suggested method exists: A. Trust the tone B. Compile it and read the official docs C. Ask the same assistant again D. Ignore it
**Q06 (O3)** A good question includes: A. Only "it doesn't work" B. Goal, code, exact error, and what you tried C. The whole project D. Your password
**Q07 (O3)** For the error part of your question, paste: A. A guess B. The exact error message or stack trace C. A screenshot of the desktop D. Nothing
**Q08 (O4)** Before asking, you should: A. Try first and write a hypothesis B. Copy the assignment C. Skip debugging D. Ask for a full solution
**Q09 (O4)** After getting an answer, you should: A. Paste it and move on B. Explain it back in your own words and verify it C. Delete it D. Ask for more code
**Q10 (O5)** Never paste into a chat: A. A short method without secrets B. API keys, passwords, or personal data C. An error message with no secrets D. A variable name

## Answers
Q01 B · Q02 B · Q03 A · Q04 B · Q05 B · Q06 B · Q07 B · Q08 A · Q09 B · Q10 B

## Practical part
Lab log for three bugs, including one case where the assistant was wrong or incomplete, plus this quiz. Pass: quiz at least 8/10 and a log showing hypothesis, assistant answer, and settling evidence for each bug.
