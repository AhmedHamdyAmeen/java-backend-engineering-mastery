# BEG-017 · Introductory algorithms — Quiz

Outcomes: O1 searching · O2 sorting · O3 counting steps.

**Q01 (O1)** Binary search requires the data to be: A. Unique B. Sorted C. Numeric strings D. Small
**Q02 (O1)** Linear search returns -1 when: A. The target is first B. The target is not found C. The array is sorted D. The target is last
**Q03 (O1)** About how many steps does binary search need for 1,000 sorted items? A. 10 B. 500 C. 1,000 D. 100
**Q04 (O1)** A safer middle calculation is: A. `(low + high) / 2` B. `low + (high - low) / 2` C. `low * high` D. `high - 1`
**Q05 (O2)** Bubble sort works by: A. Picking the smallest each time B. Swapping adjacent out-of-order items C. Halving the array D. Copying the array
**Q06 (O2)** After the first bubble-sort pass, the largest value is: A. At the start B. In the middle C. At the end D. Unchanged
**Q07 (O2)** Selection sort each pass: A. Selects the smallest remaining value and puts it next B. Swaps all neighbors C. Reverses the array D. Searches for a target
**Q08 (O3)** If n doubles, linear search work about: A. Stays the same B. Doubles C. Quadruples D. Halves
**Q09 (O3)** If n doubles, bubble sort work about: A. Doubles B. Quadruples C. Stays the same D. Adds one step
**Q10 (O3)** Which grows slowest as n grows? A. Linear search B. Bubble sort C. Binary search D. Selection sort

## Answers
Q01 B · Q02 B · Q03 A · Q04 B · Q05 B · Q06 C · Q07 A · Q08 B · Q09 B · Q10 C
