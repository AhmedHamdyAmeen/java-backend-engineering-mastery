# BEG-006 · Command line — Quiz

Outcomes: O1 paths · O2 files · O3 pipes · O4 variables · O5 permissions.

**Q01 (O1)** `cd ..` moves you to: A. The home folder B. The parent folder C. The root D. A new folder
**Q02 (O1)** An absolute path: A. Starts from the root B. Starts from where you are C. Never has slashes D. Is always short
**Q03 (O1)** `pwd` shows: A. Your password B. Your current folder C. Your processes D. Your PATH
**Q04 (O2)** Which command copies a file in Bash? A. `mv` B. `cp` C. `rm` D. `cd`
**Q05 (O2)** Deleting from the terminal: A. Goes to the recycle bin B. Is permanent C. Can always be undone D. Asks twice
**Q06 (O3)** `>` does what? A. Writes output to a file B. Reads a file C. Deletes a file D. Lists files
**Q07 (O3)** `|` (pipe) does what? A. Sends one command's output to the next B. Ends a command C. Makes a folder D. Renames a file
**Q08 (O4)** Which sets a variable for the current session in Bash? A. `export NAME=value` B. `cd NAME` C. `ls NAME` D. `rm NAME`
**Q09 (O4)** In PowerShell, you read variable `X` with: A. `$env:X` B. `%X` C. `echo X` D. `X()`
**Q10 (O5)** "Permission denied" when running a script usually means: A. The script lacks execute permission B. The disk is full C. RAM is full D. Java is missing

## Answers
Q01 B · Q02 A · Q03 B · Q04 B · Q05 B · Q06 A · Q07 A · Q08 A · Q09 A · Q10 A

## Practical part
Timed terminal task: 10 commands (navigate, create, copy, move, redirect, filter, set a variable) with no GUI use, 15 minutes. Pass: at least 8 of 10 correct.
