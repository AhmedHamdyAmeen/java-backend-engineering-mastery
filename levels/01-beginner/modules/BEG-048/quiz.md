# BEG-048 · Data fundamentals — Quiz

Outcomes: O1 why databases · O2 relational vs nonrelational · O3 DBMS and schema.

**Q01 (O1)** A main benefit of a database over a plain file is: A. Safe access by many users B. Smaller screen C. No need for a computer D. Free Java
**Q02 (O1)** What happens if two programs save the same CSV file at once? A. Both changes merge perfectly B. The file is locked forever C. One update can overwrite the other D. Nothing can happen
**Q03 (O1)** Searching a huge file means: A. Instant lookup always B. Reading much of the file C. Using SQL D. Using a schema
**Q04 (O2)** Relational databases store data in: A. Tables with rows and columns B. Photos C. Only JSON D. Only key-value pairs
**Q05 (O2)** Which is a nonrelational style? A. A table with a primary key B. A foreign key C. A document store D. A junction table
**Q06 (O2)** "NoSQL is always faster." This is: A. True B. True for small data C. True on Linux D. False; it depends on the workload
**Q07 (O2)** A JSON response is usually: A. Unstructured B. Semi-structured C. A schema D. A DBMS
**Q08 (O3)** PostgreSQL is a: A. Schema B. Table C. DBMS D. Column
**Q09 (O3)** A schema describes: A. The data's structure and rules B. The network C. The user's password D. The screen layout
**Q10 (O3)** Which is the blueprint and which the contents? A. Rows are the blueprint B. Schema is the blueprint, rows are contents C. They are the same D. DBMS is the contents

## Answers
Q01 A · Q02 C · Q03 B · Q04 A · Q05 C · Q06 D · Q07 B · Q08 C · Q09 A · Q10 B
