# BEG-022 · Inheritance — Quiz (is-a or has-a?)

Outcomes: O1 extends/super/override · O2 what is inherited · O3 is-a vs has-a.

**Q01 (O1)** Which keyword creates a subclass? A. `implements` B. `inherits` C. `extends` D. `super`
**Q02 (O1)** `super(...)` in a constructor must be: A. The first statement B. The last statement C. Anywhere D. Optional always
**Q03 (O1)** `@Override` helps because: A. It speeds up code B. The compiler checks that you really override C. It makes a method static D. It hides the method
**Q04 (O1)** How many direct superclasses can a Java class have? A. Zero B. Two C. Any number D. One
**Q05 (O2)** Which is NOT inherited by a subclass? A. Constructors B. Protected fields C. Public methods D. Public fields
**Q06 (O2)** A `final` method: A. Is static B. Must be overridden C. Cannot be overridden D. Is private
**Q07 (O3)** Is-a or has-a: a Car and its Engine. A. is-a B. neither C. both D. has-a
**Q08 (O3)** Is-a or has-a: a SavingsAccount and an Account. A. has-a B. is-a C. neither D. static
**Q09 (O3)** Composition means: A. A class holds another object in a field B. A class extends two classes C. A class is final D. A class is abstract
**Q10 (O3)** A good reason to avoid inheritance is: A. The parent is well designed for extension B. The child is a kind of the parent C. You want polymorphism D. The child needs only some of the parent's methods

## Answers
Q01 C · Q02 A · Q03 B · Q04 D · Q05 A · Q06 C · Q07 D · Q08 B · Q09 A · Q10 D
