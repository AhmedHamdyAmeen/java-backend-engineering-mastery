# BEG-047 · GitHub — Quiz

Outcomes: O1 remotes, push, pull · O2 pull requests · O3 README.

**Q01 (O1)** The usual name of the main remote is: A. `main` B. `server` C. `origin` D. `github`
**Q02 (O1)** Which command sends local commits to the remote? A. `git pull` B. `git push` C. `git clone` D. `git init`
**Q03 (O1)** Which command copies an existing remote repo to your computer? A. `git clone` B. `git push` C. `git add` D. `git merge`
**Q04 (O1)** With SSH keys, what do you upload to GitHub? A. The private key B. Your password C. The public key D. Nothing
**Q05 (O1)** Where should a personal access token be stored? A. In the README B. In a commit C. In the code D. In a safe place outside the repo
**Q06 (O2)** A pull request is: A. A request to merge one branch into another B. A download of the repo C. A deleted branch D. A password reset
**Q07 (O2)** After a review comment you should: A. Open a new repo B. Push more commits to the same branch C. Delete the PR D. Push to `main`
**Q08 (O2)** Why avoid pushing directly to `main`? A. It is impossible B. It deletes history C. It skips review D. It needs a token
**Q09 (O3)** Markdown for a level-one heading: A. `# Title` B. `<title>` C. `== Title ==` D. `**Title**`
**Q10 (O3)** Which README part is most often missing? A. A logo B. Setup steps C. A license joke D. Emojis

## Answers
Q01 C · Q02 B · Q03 A · Q04 C · Q05 D · Q06 A · Q07 B · Q08 C · Q09 A · Q10 B
