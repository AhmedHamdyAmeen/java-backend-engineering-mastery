# BEG-052 · Web fundamentals — Quiz

Outcomes: O1 request and response anatomy · O2 methods and status codes · O3 JSON · O4 URLs.

**Q01 (O1)** A response always includes: A. A status code B. A method C. A query string D. A fragment
**Q02 (O1)** HTTP being stateless means: A. Each request stands alone B. It has no errors C. It has no headers D. It cannot send JSON
**Q03 (O2)** Which method should only read data? A. `POST` B. `DELETE` C. `PUT` D. `GET`
**Q04 (O2)** Create a new resource with: A. `GET` B. `POST` C. `DELETE` D. `HEAD`
**Q05 (O2)** A 404 means: A. Server crashed B. Redirect C. Not found D. Success
**Q06 (O2)** Status class for server errors: A. 2xx B. 3xx C. 4xx D. 5xx
**Q07 (O2)** The header that tells the body format: A. `Host` B. `Content-Type` C. `Cookie` D. `Date`
**Q08 (O3)** A JSON array maps best to a Java: A. `String` B. `int` C. `List` D. `boolean`
**Q09 (O3)** Valid JSON key quoting: A. `{name: "Ana"}` B. `{'name': "Ana"}` C. `{name = "Ana"}` D. `{"name": "Ana"}`
**Q10 (O4)** In `/books?page=2` the `page=2` is the: A. Path B. Query parameter C. Fragment D. Host

## Answers
Q01 A · Q02 A · Q03 D · Q04 B · Q05 C · Q06 D · Q07 B · Q08 C · Q09 D · Q10 B

## Practical part
The assessment is this quiz; the lab (BEG-052-LAB1) checks five annotated requests. Pass: at least 8 of 10 quiz questions and all lab parts correctly labeled.
