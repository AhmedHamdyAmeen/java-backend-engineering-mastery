# BEG-030 · Collections — Quiz (collection choice)

Outcomes: O1 List/Set/Map/Queue · O2 choosing implementations · O3 safe iteration · O4 interface types.

**Q01 (O1)** Which collection does not allow duplicate elements? A. `List` B. `Queue` C. `Map` values D. `Set`
**Q02 (O1)** Which stores key-value pairs? A. `Map` B. `Set` C. `List` D. `Queue`
**Q03 (O1)** A first-in, first-out waiting line is a: A. `Set` B. `Queue` C. `Map` D. `TreeSet`
**Q04 (O2)** You want unique names kept sorted. Use: A. `ArrayList` B. `HashSet` C. `HashMap` D. `TreeSet`
**Q05 (O2)** Default general-purpose list: A. `LinkedList` B. `TreeMap` C. `ArrayList` D. `HashSet`
**Q06 (O2)** Fast lookup of an order by its id: A. `HashMap` B. `ArrayList` C. `LinkedList` D. `ArrayDeque`
**Q07 (O2)** Which map keeps keys in sorted order? A. `HashMap` B. `LinkedHashMap` C. `Hashtable` D. `TreeMap`
**Q08 (O3)** Removing from a list inside a for-each usually causes: A. `ConcurrentModificationException` B. A faster loop C. `NullPointerException` D. Nothing
**Q09 (O3)** A simple safe way to remove matching elements: A. `list.clear()` B. `list.removeIf(...)` C. Remove inside for-each D. `list.get(i)`
**Q10 (O4)** Which declaration is best style? A. `ArrayList<String> x = new ArrayList<>();` B. `Object x = new ArrayList<String>();` C. `List<String> x = new ArrayList<>();` D. `var x = null;`

## Answers
Q01 D · Q02 A · Q03 B · Q04 D · Q05 C · Q06 A · Q07 D · Q08 A · Q09 B · Q10 C
