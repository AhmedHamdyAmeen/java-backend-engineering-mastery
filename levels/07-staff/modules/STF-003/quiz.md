# STF-003 · Architecture governance at scale — Quiz

Outcomes: O1 principles · O2 reference architectures · O3 decision rights · O4 scalable governance and its cost.

**Q01 (O1)** Which principle is usable in a dispute? A. Build scalable systems B. Use best practices C. Keep things simple D. Prefer async events between domains except for user-facing reads
**Q02 (O1)** A principle is a platitude if: A. Nobody could reasonably choose the opposite B. It has an example C. It states a trade-off D. It has an owner
**Q03 (O2)** A reference architecture is most useful when shipped with: A. A slide deck only B. A runnable template and an owner C. A mandate with no code D. A vendor contract
**Q04 (O2)** A team deviates from the reference architecture. Best handling: A. Block the release B. Ignore it C. Record the reason and treat it as feedback D. Fire the team
**Q05 (O3)** Who decides a single team's internal design? A. Organization board B. CTO C. Security D. The team
**Q06 (O3)** A decision-rights entry should include: A. Only the decider B. Decider, consulted parties, and response time C. Only a deadline D. Only a tool name
**Q07 (O4)** Which metric measures governance cost? A. Review turnaround time B. Lines of code C. Number of principles D. Server count
**Q08 (O4)** A high bypass rate suggests: A. The process is perfect B. Teams love meetings C. The process costs too much or helps too little D. Too few teams
**Q09 (O4)** At 20 teams, the best way to scale reviews is: A. One board for everything B. No review at all C. Weekly all-hands approval D. Decisions at lowest level, automated guardrails, light review of cross-team items
**Q10 (O3)** Which belongs at the organization level? A. A team's variable names B. A team's test framework C. The identity provider D. A single service's internal cache

## Answers
Q01 D · Q02 A · Q03 B · Q04 C · Q05 D · Q06 B · Q07 A · Q08 C · Q09 D · Q10 C

## Practical part
Six case exercises `STF-003-EX01` to `EX06` plus the lab, reviewed as a governance model with a role-played team lead. Pass: at least five of six exercises correct, quiz at least 8/10, and a model in which the team lead names the decider and speed for five sample decisions.
