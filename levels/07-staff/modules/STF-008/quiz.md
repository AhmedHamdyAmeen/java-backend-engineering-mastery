# STF-008 · Security architecture strategy — Quiz

Outcomes: O1 threat landscape and controls · O2 trust boundaries and identity · O3 secure defaults · O4 joint roadmap with security.

**Q01 (O1)** Recurring audit findings in most teams call for: A. More reviews B. Training only C. A strategy that removes the class of finding D. Ignoring them
**Q02 (O1)** Ranking threats helps because: A. Effort is limited and should go to the largest risks B. It is fashionable C. All threats are equal D. It replaces controls
**Q03 (O2)** Between internal services, the better stance is: A. Trust the network B. Authenticate each call C. Share one password D. No logging
**Q04 (O2)** Trust boundaries should be: A. Secret B. Documented so teams place systems correctly C. Drawn once D. Ignored for partners
**Q05 (O2)** One identity strategy should cover: A. Employees only B. Customers only C. People, services, and partners D. Admins only
**Q06 (O3)** A secure default is best because it: A. Needs memory B. Needs a meeting C. Needs a checklist D. Works without extra effort from teams
**Q07 (O3)** The right test for a default is that it removes: A. A class of findings B. One finding C. A meeting D. A team
**Q08 (O3)** Where should supply-chain scanning and signing run? A. In each team's own script B. Only on laptops C. In the shared pipeline D. Never
**Q09 (O4)** In a joint roadmap, who owns default enforcement in the platform? A. The security team alone B. The platform team in partnership with security C. Each product team D. Auditors
**Q10 (O4)** A joint roadmap fails when it: A. Has measures B. Has owners C. Meets regularly D. Is a one-time document

## Answers
Q01 C · Q02 A · Q03 B · Q04 B · Q05 C · Q06 D · Q07 A · Q08 C · Q09 B · Q10 D

## Practical part
Six case exercises `STF-008-EX01` to `EX06` plus the lab, reviewed as a strategy with a role-played CISO. Pass: at least five of six exercises correct, quiz at least 8/10, and a strategy in which each default removes a class of findings.
