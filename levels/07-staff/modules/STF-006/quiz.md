# STF-006 · Cross-domain systems — Quiz

Outcomes: O1 cross-domain capabilities and coupling · O2 shared versus domain-owned · O3 ownership and funding · O4 evolving shared systems.

**Q01 (O1)** Which is a typical cross-domain capability? A. A team's unit test helper B. Customer identity C. A UI color D. A feature flag in one service
**Q02 (O1)** Teams duplicate shared systems mainly because: A. They enjoy it B. Rules require it C. They cannot rely on the shared one to change when needed D. Cloud costs less
**Q03 (O1)** Three customer-identity systems cause: A. Diverging records and inconsistent security and experience B. Faster logins C. Lower cost D. No risk
**Q04 (O2)** Share a capability when: A. Many domains need the same stable behavior and consistency matters B. Needs differ widely C. It changes weekly with one domain D. No team will own it
**Q05 (O2)** A shared system with no API or service level is: A. A platform B. A trap C. Ideal D. A domain
**Q06 (O3)** Each shared system should have: A. Several equal owners B. No on-call C. Only a wiki page D. One accountable team with on-call and roadmap
**Q07 (O3)** Pure chargeback for a core shared service can: A. Increase adoption B. Always reduce cost C. Discourage teams from using it D. Remove need for owners
**Q08 (O4)** The safest way to change a shared API is: A. Overnight replacement B. Side-by-side versions with stepwise migration C. Delete the old one D. Announce by email only
**Q09 (O4)** A consolidation plan is good when: A. It decrees a date B. It ignores consumer roadmaps C. It keeps every consumer working at each step D. It skips testing
**Q10 (O3)** Without funding, a shared system tends to: A. Improve B. Stay static C. Gain consumers D. Decay

## Answers
Q01 B · Q02 C · Q03 A · Q04 A · Q05 B · Q06 D · Q07 C · Q08 B · Q09 C · Q10 D

## Practical part
Six case exercises `STF-006-EX01` to `EX06` plus the lab, defended as a recommendation to role-played consumers. Pass: at least five of six exercises correct, quiz at least 8/10, and a consolidation plan that keeps every consumer working at each step.
