# STF-022 · Leading an AI adoption program — Exercises and lab

## Lab
### STF-022-LAB1 · AI adoption program
**Outcomes:** 1–4 · **Time:** ~3.5 h
1. Write a two-quarter adoption program for Platform 2.0: outcome, groups, champions, enablement, community, support.
2. Write the concerns table and the risk register with pause triggers and an incident runbook.
3. Write the executive report template with baseline, outcomes, trade-offs, and decisions.
4. The assessor injects an event (a secret leaked through an AI tool, or a defect spike); respond.
5. Produce the executive report for the event period.
**Acceptance:** response follows the program's risk plan; executive report states outcomes and trade-offs.

## Exercises (case-based; six exercises)
| ID | Outcome | Task |
| --- | --- | --- |
| STF-022-EX01 | 1 | Leadership wants "80% of engineers using AI tools by Q2". Rewrite the target as outcome measures and explain why. |
| STF-022-EX02 | 1 | Design a champion program for 20 teams: selection, time allocation, enablement, and support route. |
| STF-022-EX03 | 2 | A senior engineer says AI tools will deskill juniors. Write an honest response with evidence, uncertainty, and an action. |
| STF-022-EX04 | 3 | Write pause triggers for quality, security, and cost, with owners and responses. |
| STF-022-EX05 | 3 | A developer pasted a production API key into an AI chat. Write the first-hour response. |
| STF-022-EX06 | 4 | Draft the one-page executive report after one quarter: some outcomes improved, defects rose in one team; state trade-offs and adjustments. |

## Solutions
- **EX01** Targets: lead time for small changes, defect escape rate, incident count, developer sentiment, cost per engineer, against baseline. Usage percentages encourage show-use and hide quality.
- **EX02** One champion per team with 10% time, selected by volunteering and credibility; monthly enablement on real code; shared channel; escalation to security and platform AI team.
- **EX03** Acknowledge the concern; share what is known and unknown; keep code review and pairing; add learning goals for juniors and measure; invite them to design the guidelines.
- **EX04** Quality: escape rate above agreed threshold for two sprints; security: any confirmed secret exposure; cost: spend above budget by agreed percent; owners pause and report same day.
- **EX05** Rotate the key immediately, check logs for use, assess exposure per tool terms, notify security, document, review the guardrails (secret scanning, training), blameless review.
- **EX06** Summary, outcome table against baseline, the defect rise with cause and fix, cost, risks, decisions requested; honest about uncertainty; next-quarter changes.

Outcome 2 is also covered by the lab concerns table.

**Workplace evidence:** an AI adoption effort you led and its measured outcome.
