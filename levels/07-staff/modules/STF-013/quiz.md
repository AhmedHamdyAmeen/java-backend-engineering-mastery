# STF-013 · Cross-team programs — Quiz

Outcomes: O1 milestones and owners · O2 dependencies and critical path · O3 accountability without authority · O4 escalation.

**Q01 (O1)** A good milestone is: A. A list of tasks B. A date C. A verifiable state with one owner D. A team name
**Q02 (O1)** What most distinguishes a program from a project? A. It lasts longer B. It coordinates several independent teams toward one outcome C. It has a bigger budget D. It needs more code
**Q03 (O1)** Programs usually fail on: A. Language choice B. Coordination C. Code quality D. Testing tools
**Q04 (O2)** The critical path is: A. The riskiest task B. The most expensive task C. The shortest chain D. The chain of dependent work that sets the end date
**Q05 (O2)** A one-week slip on a critical-path task: A. Moves the end date B. Is absorbed C. Affects nothing D. Is the TPM's problem only
**Q06 (O2)** The dependency map should be reviewed: A. Once at the start B. Only when something fails C. Every cycle D. At the end
**Q07 (O3)** Commitments are strongest when agreed with: A. Only the engineer B. The engineer and their manager C. Only the sponsor D. Nobody, informally
**Q08 (O3)** A weekly program review should mainly spend time on: A. Reading all status aloud B. Green items C. Retrospectives D. Blockers and decisions on the critical path
**Q09 (O4)** A good escalation includes: A. The name of who is at fault B. Impact, options, a recommendation, and a decision date C. A request for more time D. Only the problem
**Q10 (O4)** When should you escalate a blocked critical-path dependency? A. At the final week B. Never C. When you cannot resolve it and the date is at risk D. After a postmortem

## Answers
Q01 C · Q02 B · Q03 B · Q04 D · Q05 A · Q06 C · Q07 B · Q08 D · Q09 B · Q10 C

## Practical part
Six case exercises `STF-013-EX01` to `EX06` plus the lab with the assessor-injected slip, assessed in a program review simulation. Pass: at least five of six exercises correct, quiz at least 8/10, and a response that protects the critical path and is communicated within one cycle.
