# MID-065 · Engineering ownership — Quiz

Outcomes: O1 what ownership means · O2 prioritization with evidence · O3 readiness checklist · O4 communicating as an owner.

**Q01 (O1)** Owning a service means: A. Having written the first version B. Being the only person who can change it C. Answering for it in production, including on-call, SLOs, and cost D. Approving every pull request
**Q02 (O1)** An alert that pages a human should: A. Fire on every error B. Indicate a user-facing problem needing action and link to a runbook C. Be ignored at night D. Replace a dashboard
**Q03 (O1)** In an incident, first: A. Find the root cause B. Write the report C. Blame the change author D. Mitigate to limit impact
**Q04 (O2)** A spent error budget suggests: A. More feature work B. Reliability work first C. Removing the SLO D. Hiring
**Q05 (O2)** Best way to argue for paying down debt: A. "The code is ugly" B. "I dislike this module" C. "It costs two days per release and caused three incidents" D. "Everyone knows it"
**Q06 (O2)** A debt list that is never prioritized is: A. Fine B. A complaint list C. A roadmap D. A runbook
**Q07 (O3)** A backup is proven ready by: A. A scheduled job existing B. A green dashboard C. A successful restore test D. A policy document
**Q08 (O3)** A readiness gap you decide to accept should be: A. Hidden B. Ignored C. Fixed before anything else D. Recorded with an owner who accepted the risk
**Q09 (O4)** A message to product should start with: A. Technical detail B. Impact and the decision needed C. An apology D. A log excerpt
**Q10 (O4)** Reporting health in SLO terms means: A. "It feels fine" B. CPU usage only C. "99.7% of checkouts succeeded against a 99.9% target" D. Number of deployments

## Answers
Q01 C · Q02 B · Q03 D · Q04 B · Q05 C · Q06 B · Q07 C · Q08 D · Q09 B · Q10 C
