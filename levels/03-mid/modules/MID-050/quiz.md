# MID-050 · Incident handling — Quiz

Outcomes: O1 triage · O2 mitigate first · O3 timeline and communication · O4 blameless postmortems.

**Q01 (O1)** First triage questions are about: A. Who to blame B. Code style C. Who is affected and how badly D. The next release
**Q02 (O1)** If impact is unclear and potentially high, you should: A. Wait B. Escalate early C. Close the incident D. Restart everything
**Q03 (O1)** Checkout failing for all customers is typically: A. Sev3 B. Sev2 C. No severity D. Sev1
**Q04 (O2)** During an incident prioritize: A. Mitigation such as rollback B. Root-cause analysis C. Refactoring D. Writing the postmortem
**Q05 (O2)** The fastest safe mitigation for a bad deploy is usually: A. Debug the code B. Roll back C. Add servers D. Wait
**Q06 (O2)** Verify mitigation by: A. A feeling B. The absence of messages C. The SLI recovering D. Asking the team
**Q07 (O3)** The incident commander: A. Debugs the code B. Coordinates and decides C. Writes the code fix D. Talks to no one
**Q08 (O3)** A status update includes: A. A joke B. A guess of blame C. Only the time D. Impact, what we know, what we do, next update
**Q09 (O4)** A blameless postmortem: A. Names the culprit B. Skips action items C. Looks at contributing factors in the system D. Is optional for Sev1
**Q10 (O4)** Action items should have: A. Owners, due dates, and tracking B. No owner C. Only ideas D. Only a title

## Answers
Q01 C · Q02 B · Q03 D · Q04 A · Q05 B · Q06 C · Q07 B · Q08 D · Q09 C · Q10 A

## Practical part
Seven exercises `MID-050-EX01` to `EX07` plus the game-day lab. Pass: at least five exercises, a mitigation within the time box, and a reviewed blameless postmortem.
