# SRB-022 · AI tools across teams — Quiz

Outcomes: O1 rollout planning · O2 usage policy · O3 tool security review · O4 honest measurement.

**Q01 (O1)** Your teams already use assistants individually. What should the lead do first? A. Ban them B. Make adoption visible with a pilot, policy, and measurement C. Wait for vendors D. Mandate use
**Q02 (O1)** Why include a skeptical team in a pilot? A. To reduce selection bias and see real objections B. To slow the pilot C. To save cost D. Skeptics write better prompts
**Q03 (O1)** A pilot widening gate should require: A. A deadline B. Executive enthusiasm C. Policy, security approval, and reviewed metrics D. More licenses
**Q04 (O2)** In a usage policy, who is accountable for AI-generated code in a pull request? A. The vendor B. The assistant C. The reviewer only D. The author who submits it
**Q05 (O2)** Which belongs in a usage policy? A. Allowed and forbidden data types, secrets rule, and review requirement B. Preferred prompt styles only C. Vendor marketing D. Team lunch rules
**Q06 (O3)** A key retention question for a tool is: A. How colorful is the UI? B. How many languages are supported? C. How long are prompts and outputs stored and can they be deleted? D. How fast is autocomplete?
**Q07 (O3)** Which is an integration risk to review? A. IDE plugin permissions and prompt injection via content the tool reads B. Font choice C. Keyboard shortcuts D. Theme colors
**Q08 (O4)** Which is a vanity metric? A. Change failure rate B. Developer experience survey C. Lines of code generated D. Lead time
**Q09 (O4)** Pilot teams ship more PRs, and so does the control team. What follows? A. The tool caused the rise B. Part of the rise was not due to the tool C. The control is invalid D. Stop measuring
**Q10 (O4)** A known side effect to measure when generated code increases is: A. Printer use B. Meeting length C. Review load D. Office space

## Answers
Q01 B · Q02 A · Q03 C · Q04 D · Q05 A · Q06 C · Q07 A · Q08 C · Q09 B · Q10 C

## Practical part
Defend the rollout plan (SRB-022 assessment) and complete `SRB-022-LAB1`. Pass: at least 8/10 on the quiz, a policy approved by the role-played security lead, and a measurement plan with a baseline and a defect-rate check.
