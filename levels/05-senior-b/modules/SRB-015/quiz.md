# SRB-015 · Cost optimization — Quiz

Outcomes: O1 cost drivers · O2 attribution and unit economics · O3 optimization levers · O4 cost versus reliability.

**Q01 (O1)** Which is a major cloud cost driver? A. Code comments B. Data transfer between zones and regions C. Unit tests D. Git branches
**Q02 (O1)** Unattached disks and forgotten environments are examples of: A. Autoscaling B. Commitments C. Idle resources D. Tagging
**Q03 (O2)** Untagged spend is a problem because: A. It has no cost B. It is free C. Tags are billed D. Nobody owns it and attribution is unreliable
**Q04 (O2)** Cost per order is useful because: A. It shows efficiency as volume grows B. It is always lower C. It replaces budgets D. It lowers cloud bills
**Q05 (O2)** For shared cluster costs you should: A. Ignore them B. Assign all to one team C. Allocate with a stated rule such as usage D. Divide randomly
**Q06 (O3)** Rightsizing means: A. Buying larger instances B. Matching resources to measured usage C. Reducing headcount D. Moving regions
**Q07 (O3)** Commitments suit: A. Spiky unpredictable load B. Experiments C. Steady baseline load D. Idle resources
**Q08 (O4)** A saving that removes a standby replica should be checked against: A. Developer opinion B. Naming rules C. Last month's bill only D. Availability commitment and recovery objective
**Q09 (O3)** The best first target for savings is: A. The smallest line items B. The top cost drivers C. Free services D. Randomly chosen items
**Q10 (O4)** Weighing a saving against engineering time means: A. Ignoring savings under 10% B. Never optimizing C. Comparing saving over time with the effort and risk to deliver it D. Only choosing quick wins
