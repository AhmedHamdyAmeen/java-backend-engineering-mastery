# SRC-017 · Technical debt — Quiz

Outcomes: O1 classifying debt and its interest · O2 register and prioritization · O3 incremental paydown · O4 business case.

**Q01 (O1)** The "interest" of technical debt is: A. The extra cost paid on every change in that area B. A bank fee C. Server cost only D. Lines of code
**Q02 (O1)** Which is a deliberate, prudent decision? A. Skipping tests with no plan B. Shipping a known shortcut with a dated plan to fix it C. Not knowing better patterns D. Copy-paste without understanding
**Q03 (O1)** Which is NOT technical debt? A. Missing tests in changing code B. A known design shortcut C. A bug in a feature D. Duplicated logic that slows changes
**Q04 (O2)** A debt register is only useful if items have: A. Costs and evidence B. Colorful labels C. Long names D. Anonymous owners
**Q05 (O2)** Priority rises when: A. The code is old B. The code is ugly C. A developer complains D. Heavy work is planned in that area
**Q06 (O3)** The boy-scout rule means: A. Leave code slightly better than found B. Rewrite everything C. Ban refactoring D. Only fix on Fridays
**Q07 (O3)** A strangler approach: A. Deletes the old system at once B. Replaces the old piece by piece behind a routing layer C. Prohibits new code D. Needs no tests
**Q08 (O3)** Before refactoring untested code you should: A. Add characterization tests B. Rename everything C. Merge branches D. Delete tests
**Q09 (O4)** A pitch to leadership should show: A. Only technical details B. Only complaints C. Cost of delay, options, and expected outcomes D. A demand for a rewrite
**Q10 (O4)** After a debt item is funded and done, you should: A. Report the measured results B. Say nothing C. Start a rewrite D. Hide the numbers

## Answers
Q01 A · Q02 B · Q03 C · Q04 A · Q05 D · Q06 A · Q07 B · Q08 A · Q09 C · Q10 A

## Practical part
Pitch and register review (SRC-017 assessment), plus the `SRC-017-LAB1` register and pitch. Pass: at least 8/10 on the quiz, a register with costs for every item, and at least one item approved on its business case.
