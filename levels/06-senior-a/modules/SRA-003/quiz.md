# SRA-003 · Complex domain modeling — Quiz

Outcomes: O1 strategic DDD and subdomains · O2 context maps · O3 anti-corruption layers · O4 collaborative modeling.

**Q01 (O1)** A bounded context is: A. A database schema B. A team's backlog C. A boundary within which a model and its words mean one thing D. A deployment unit
**Q02 (O1)** Where should the best engineers and in-house building be focused? A. Generic subdomains B. Core subdomains C. Supporting subdomains D. Spreadsheets
**Q03 (O1)** Payments and email for a marketplace are usually: A. Core B. Unknown C. Supporting only D. Generic, so buy or adopt
**Q04 (O2)** A downstream team that accepts the upstream model with no influence is a: A. Partner B. Customer C. Conformist D. Supplier
**Q05 (O2)** A stable documented interface and shared format offered by an upstream team is an: A. Open host service with published language B. Anti-corruption layer C. Conformist D. Partnership
**Q06 (O2)** A context map that merely mirrors the org chart is a problem because: A. Org charts are secret B. It never examines whether the boundaries are right C. Maps must be round D. It is too accurate
**Q07 (O3)** An anti-corruption layer mainly: A. Speeds up the network B. Stores backups C. Translates the foreign model at the boundary D. Encrypts data
**Q08 (O3)** The best reason to skip an ACL: A. The vendor is famous B. The external model fits the domain and is stable C. It is too much code D. The team is new
**Q09 (O4)** In event storming, boundary candidates often appear where: A. The wall ends B. Tables are created C. The meeting ends D. Language or ownership changes
**Q10 (O4)** Technical events like "row inserted" on the wall mean: A. The session needs to restart at the business level B. Success C. A subdomain is core D. Time to deploy

## Answers
Q01 C · Q02 B · Q03 D · Q04 C · Q05 A · Q06 B · Q07 C · Q08 B · Q09 D · Q10 A
