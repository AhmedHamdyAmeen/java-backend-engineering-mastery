# ARC-025 · API management — Quiz

Outcomes: O1 what API management provides · O2 governance and lifecycle · O3 quotas and tiers · O4 APIs as products.

**Q01 (O1)** Which is a developer portal's role? A. Routing traffic B. Self-service documentation and key sign-up C. Storing orders D. Encrypting disks
**Q02 (O1)** A solution with one internal consumer on a trusted network most likely: A. Needs full partner tiers B. Needs a public marketplace C. Needs a revenue model D. May not need a full API management platform
**Q03 (O2)** Which is a breaking change? A. Adding an optional field B. Removing a field consumers use C. Fixing a typo in docs D. Adding a new endpoint
**Q04 (O2)** A gateway without governance mainly: A. Centralizes inconsistency B. Improves style automatically C. Removes the need for versioning D. Eliminates reviews
**Q05 (O2)** A lifecycle policy should include: A. Only a launch date B. Only a logo C. Dates and notice periods for deprecation and retirement D. No consumers
**Q06 (O3)** Why separate keys per consumer? A. Shorter URLs B. Revocation and usage reporting per consumer C. Faster servers D. Fewer tests
**Q07 (O3)** One quota for all consumers is a mistake because: A. Quotas are illegal B. Internal use is zero C. Gateways ignore quotas D. Consumers differ in trust, volume, and contract
**Q08 (O4)** An API product has: A. An owner, consumers, documentation, and support B. Only code C. Only a gateway D. No version
**Q09 (O4)** Which measure suits API product health? A. Lines of code B. Number of servers C. Active consumers and time to first successful call D. Office size
**Q10 (O3)** Public tier consumers of Larkspur should typically get: A. Full admin rights B. Read-only catalog with low limits and no personal data C. Order edit rights D. ERP access

## Answers
Q01 B · Q02 D · Q03 B · Q04 A · Q05 C · Q06 B · Q07 D · Q08 A · Q09 C · Q10 B

## Practical part
API program review: a role-played partner manager and security lead question tiers, quotas, onboarding, and deprecation. Pass: quiz at least 8/10, all five exercises correct, and a program with separate tiers and a written deprecation path.
