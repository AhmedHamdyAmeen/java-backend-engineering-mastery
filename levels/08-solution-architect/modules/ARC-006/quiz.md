# ARC-006 · Solution architecture lifecycle — Quiz

Outcomes: O1 lifecycle stages · O2 exit criteria and deliverables · O3 supporting delivery · O4 handover.

**Q01 (O1)** Which sequence matches the lifecycle? A. Build, design, discovery B. Options, discovery, handover C. Review, build, options D. Discovery, options, design, review, delivery support, transition, handover
**Q02 (O1)** The architect's involvement should: A. End at design approval B. Continue through delivery to handover C. Start at go-live D. Be only in options
**Q03 (O2)** An exit criterion for discovery is: A. Code complete B. A signed requirements baseline C. Go-live D. A vendor contract
**Q04 (O2)** The options stage normally delivers: A. Production code B. A runbook C. A compared set of options and a recommendation D. A test report
**Q05 (O2)** Every architecture review should have: A. A named decision-maker B. No conditions C. Only engineers D. No outputs
**Q06 (O3)** A design authority helps avoid bottlenecks by: A. Approving every commit B. Defining which changes need approval and delegating the rest C. Meeting rarely D. Replacing the decision log
**Q07 (O3)** A decision log entry contains: A. Context, decision, alternatives, consequences, owner B. Code C. Test data D. Timesheets
**Q08 (O3)** A common mistake is: A. Office hours B. Decision records C. Disappearing after design approval D. Review conditions
**Q09 (O4)** A handover pack should include: A. Only diagrams B. Runbooks, monitoring, risks, contacts, decision log C. Vendor invoices D. Source code only
**Q10 (O4)** Handover is complete when: A. Design is approved B. The code is merged C. The sponsor is happy D. Operations accepts against agreed criteria

## Answers
Q01 D · Q02 B · Q03 B · Q04 C · Q05 A · Q06 B · Q07 A · Q08 C · Q09 B · Q10 D

## Practical part
Plan review of the lab architecture work plan and exercises `ARC-006-EX01` to `EX06`. Pass: quiz at least 8/10, at least five of six exercises correct, and a plan aligned to the program with a decision-maker for every review.
