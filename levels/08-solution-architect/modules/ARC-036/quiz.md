# ARC-036 · Solution roadmaps — Quiz

Outcomes: O1 phases that deliver value · O2 dependency mapping · O3 milestones and exit criteria · O4 keeping the roadmap current.

**Q01 (O1)** A roadmap where value arrives only at month 18 is risky because: A. Months are long B. Everything is tested early C. The team is too large D. Funding cuts can leave nothing usable
**Q02 (O1)** Which slicing delivers usable capability each phase? A. Database first, then services, then UI B. Vertical slices by capability C. By team name D. Alphabetical order
**Q03 (O1)** Why include a thin ERP stock interface in phase one? A. It is cheap B. Phase one needs it and it is the riskiest unknown C. ERP is a vendor D. It is plumbing
**Q04 (O2)** Which is a vendor dependency? A. Store staff training B. The ERP API being built by your team C. A SaaS vendor delivering a feature on its own date D. A data model
**Q05 (O2)** Which is a contractual dependency? A. A notice period in the hosting contract B. A code library C. A sprint D. A diagram tool
**Q06 (O2)** Which dependencies are most often left implicit? A. Technical ones B. Unit tests C. Variable names D. Vendor and contractual ones
**Q07 (O3)** Which is a good milestone? A. "Development finished" B. "Ten pilot stores taking orders with errors under the agreed limit" C. "Sprint 12" D. "Architecture done"
**Q08 (O3)** Good exit criteria are: A. Measurable and agreed in advance B. Agreed after delivery C. Subjective D. Set by the vendor only
**Q09 (O4)** A roadmap should be updated: A. Never B. Only at project end C. At regular reviews and after major scope, funding, or vendor changes D. Only when asked by finance
**Q10 (O4)** When the roadmap changes, you should: A. Replace it silently B. Record the change with its reason C. Delete the old version D. Hide the change from sponsors

## Answers
Q01 D · Q02 B · Q03 B · Q04 C · Q05 A · Q06 D · Q07 B · Q08 A · Q09 C · Q10 B

## Practical part
Roadmap review on the Larkspur lab: phases with value statements, a four-type dependency map, measurable exit criteria, and a review rhythm. Pass: quiz at least 8/10, at least four of five exercises correct, and a lab whose phase one delivers measurable value on its own.
