# ARC-033 · Solution options — Exercises and lab

## Lab
### ARC-033-LAB1 · Larkspur options analysis
**Outcomes:** 1–4 · **Time:** ~4 h
1. Draft at least three genuinely different options (commerce SaaS, packaged platform, custom build, hybrid) plus the "extend the old web shop" baseline.
2. Run a role-played stakeholder workshop and record gates, criteria, weights, and who endorsed them before scoring.
3. Score each option in a decision matrix with an evidence note per score.
4. Run sensitivity analysis: vary each weight and report whether the winner changes.
5. Write the recommendation, and for each rejected option record its honest strengths and why it lost.
6. Defend the analysis to an assessor who challenges your weights and scores.
**Acceptance:** rejected options documented with their honest strengths.

## Exercises (case-based; six exercises)
| ID | Outcome | Task |
| --- | --- | --- |
| ARC-033-EX01 | 1 | A project brief for Larkspur lists "Option A: buy Platform X; Option B: build everything from scratch with no budget for testing; Option C: do nothing and lose the market". Explain what is wrong and rewrite as three credible options. |
| ARC-033-EX02 | 1 | Write a half-page sketch for the hybrid option (SaaS storefront plus custom order orchestration): what Larkspur owns, rents, and what the first release contains. |
| ARC-033-EX03 | 2 | Larkspur's finance director wants "cheapest" and e-commerce wants "fastest". Draft gates, six weighted criteria, and a workshop plan that settles weights before scoring. |
| ARC-033-EX04 | 3 | Given a matrix with totals 3.9 (SaaS), 3.8 (hybrid), 3.2 (custom), explain what can and cannot be concluded, and design the sensitivity tests you would run. |
| ARC-033-EX05 | 3 | In EX04, raising "process fit" by 5 points makes hybrid win. Write the message to the sponsor presenting this result honestly. |
| ARC-033-EX06 | 4 | Write the recommendation section for the SaaS option, including three rejected options with their strengths and a re-evaluation trigger. |

## Solutions
- **EX01** Option B is built to fail (no testing budget) and option C is not a real option; replace with commerce SaaS, hybrid, and extending the existing shop as baseline, each with cost, time, and risk sketches.
- **EX02** Owns: order orchestration, integration to ERP and CRM; rents: storefront, checkout, hosting; first release: web storefront with ERP stock and price sync; later: store pickup and returns orchestration.
- **EX03** Gates: PCI scope reduction, data residency, ERP integration possible. Criteria and weights summing to 100 (for example time-to-market, total cost, process fit, integration effort, exit risk, team skills); workshop with both leaders, weights recorded and signed off before scoring.
- **EX04** A 0.1 gap is within scoring noise; conclude that SaaS and hybrid are close and the decision depends on weights; test by moving each weight by 10 points, swapping top two weights, and varying scores by one point on uncertain criteria.
- **EX05** State that the result depends on how much Larkspur values process fit; present both outcomes, name the disagreement, and ask the sponsor to rule on the weight, recorded as a decision.
- **EX06** Recommend SaaS for speed and low run effort; note hybrid's strength of process fit, custom build's control, baseline's zero migration; re-evaluate if customization needs exceed the vendor's extension limits.

All four outcomes are also covered by the lab acceptance and the quiz.

**Workplace evidence:** an options analysis you led that produced a decision.
