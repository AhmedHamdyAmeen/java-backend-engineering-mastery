# ARC-008 · Technology assessment — Quiz

Outcomes: O1 build/buy/SaaS · O2 vendor evaluation · O3 proofs of concept · O4 recommendation and sensitivity.

**Q01 (O1)** A commodity capability is best: A. Built from scratch B. Kept secret C. Outsourced to nobody D. Bought or subscribed to
**Q02 (O1)** Which capability is most likely differentiating for Larkspur? A. Email delivery B. Tax calculation C. Store-aware click-and-collect promise D. Payment card processing
**Q03 (O1)** A downside of SaaS compared with build is: A. Slower start B. Less control and data held in the vendor's platform C. More servers to run D. Higher upfront hardware
**Q04 (O2)** Which question tests architecture fit? A. How many customers does the vendor have? B. What color is the UI? C. Are all functions available through documented APIs? D. Where is the vendor's office?
**Q05 (O2)** Exit cost is chiefly influenced by: A. Logo B. Data export and replaceability C. License wording only D. Team size
**Q06 (O2)** A feature checklist alone is weak because it ignores: A. Architecture fit and exit B. Price lists C. Demos D. References
**Q07 (O3)** A PoC should first test: A. The easiest feature B. The color scheme C. The vendor's slide deck D. The riskiest assumption
**Q08 (O3)** Success criteria for a PoC should be: A. Decided afterwards B. Defined before starting C. Left vague D. Chosen by the vendor
**Q09 (O4)** Sensitivity analysis shows whether: A. A vendor is financially sound B. The PoC passed C. The ranking changes with different weights or assumptions D. Costs are accurate
**Q10 (O4)** Weights for criteria should be: A. Chosen after scoring B. Agreed with stakeholders before scoring C. Set by the vendor D. Equal always
