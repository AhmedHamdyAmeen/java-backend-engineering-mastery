# ARC-021 · Cost architecture — Quiz

Outcomes: O1 sizing and cost model · O2 unit cost and sensitivity · O3 budgets and controls · O4 presenting estimates.

**Q01 (O1)** A cost model should start from: A. The cheapest price B. Load drivers and explicit pricing assumptions C. A single guess D. Last year's invoice only
**Q02 (O1)** Which items are commonly forgotten? A. Data transfer and logging B. Compute C. Database D. Storage
**Q03 (O1)** Why model normal and peak months separately? A. Peak cost differs from normal and a single month misleads B. Peak is free C. Normal is irrelevant D. Pricing is flat
**Q04 (O2)** Cost per order is: A. Total cost multiplied by orders B. Orders divided by total cost C. Only compute cost D. Total cost divided by orders
**Q05 (O2)** If most cost is fixed, growth in orders usually: A. Raises cost per order B. Lowers cost per order C. Leaves it unchanged D. Doubles it
**Q06 (O2)** A cost step (cliff) might come from: A. A bigger database tier B. A comment in code C. A new font D. A branch name
**Q07 (O3)** Budget alerts are best set: A. Only at 100 percent B. After the bill arrives C. At several thresholds with forecast alerts D. Never
**Q08 (O3)** Commitment discounts should be bought: A. Before any usage data B. After usage is stable and understood C. Randomly D. For the peak only
**Q09 (O4)** Which is the better way to present an estimate? A. A single number B. A guess without assumptions C. A range with assumptions and confidence D. A vendor quote only
**Q10 (O4)** Marking confidence per assumption helps reviewers to: A. Skip review B. Hide uncertainty C. Remove peaks D. See which numbers to challenge

## Answers
Q01 B · Q02 A · Q03 A · Q04 D · Q05 B · Q06 A · Q07 C · Q08 B · Q09 C · Q10 D

Cost model review with a role-played finance partner using `ARC-021-LAB1` plus exercises `ARC-021-EX01` to `EX06`. Pass: quiz at least 8/10, at least five of six exercises correct, every figure traceable to an assumption, and a range given.
