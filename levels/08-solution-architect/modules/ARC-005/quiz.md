# ARC-005 · Architecture modeling — Quiz

Outcomes: O1 choosing notation · O2 integration diagrams · O3 deployment diagrams · O4 consistency and models as code.

**Q01 (O1)** Which notation best shows business processes supported by applications on technology? A. C4 code level B. ArchiMate C. Entity-relationship D. Sequence diagram
**Q02 (O1)** C4 levels most used by solution architects are: A. Context and containers B. Components and code C. Code and classes D. Deployment and cost
**Q03 (O1)** To show call order and a failure branch between services, use a: A. Capability map B. Sequence diagram C. Context diagram D. Heat map
**Q04 (O1)** Before drawing a diagram you should write down: A. The tool B. The color scheme C. The vendor D. The question and the audience
**Q05 (O2)** A useful integration arrow label includes: A. Protocol, direction, data B. Team name only C. Date only D. Color
**Q06 (O2)** Larkspur's nightly ERP file should appear on an integration diagram as: A. Omitted since it is old B. A batch flow with SFTP and owner C. A synchronous API D. A database
**Q07 (O3)** Trust boundaries on a deployment diagram help reviewers see: A. Team structure B. Where data crosses zones C. Budget D. Test coverage
**Q08 (O3)** A deployment diagram should show: A. Environments and networks B. Business capabilities only C. Class fields D. User stories
**Q09 (O4)** Consistency across views is best supported by: A. Redrawing each by hand B. Different names per audience C. A single model source with shared names D. Fewer reviews
**Q10 (O4)** Keeping diagrams as code mainly gives: A. Prettier colors B. Review, versioning, and regeneration C. Less thinking D. Vendor lock-in
