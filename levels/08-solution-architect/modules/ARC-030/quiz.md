# ARC-030 · Data governance — Quiz

Outcomes: O1 ownership and stewardship · O2 data quality rules · O3 lineage · O4 access policies for consumers.

**Q01 (O1)** Good governance mainly: A. Slows every data request B. Replaces data architecture C. Makes data trusted and usable with clear owners and rules D. Is the job of the database administrator
**Q02 (O1)** The data owner is: A. The database administrator B. An accountable business role C. The vendor D. Any analyst
**Q03 (O1)** A data steward typically: A. Maintains definitions and resolves quality issues B. Approves budgets C. Runs servers D. Writes the law
**Q04 (O2)** A usable quality rule is: A. "Data should be good" B. Specific, measured, with threshold and owner C. Written but not measured D. Checked yearly by chance
**Q05 (O2)** "Every order has a channel code" is a rule of which dimension? A. Timeliness B. Uniqueness C. Completeness D. Latency
**Q06 (O2)** Quality is best checked: A. Only in the final report B. Where data enters and along the flow C. Never D. By the end user only
**Q07 (O3)** Lineage helps most with: A. Choosing colors B. Tracing where a number came from and what a change affects C. Network sizing D. Hiring
**Q08 (O3)** Lineage for the daily sales report should reach back to: A. The report only B. The warehouse only C. The ERP only D. The till and web order sources
**Q09 (O4)** For analytics consumers, a good default is: A. Full access to all tables B. Least data that serves the question, often pseudonymized C. No access D. Shared logins
**Q10 (O4)** Who approves access to a data set? A. Anyone requesting B. The network team C. The data owner D. The vendor

## Answers
Q01 C · Q02 B · Q03 A · Q04 B · Q05 C · Q06 B · Q07 B · Q08 D · Q09 B · Q10 C
