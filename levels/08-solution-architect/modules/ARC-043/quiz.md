# ARC-043 · Solution documentation — Quiz

Outcomes: O1 architecture pack · O2 decision, assumption, and risk logs · O3 keeping documentation current · O4 handover.

**Q01 (O1)** Executives, reviewers, delivery teams, and operations all ask for "the document". The best response is: A. One long document with all content B. A pack with sections by audience, linked and owned C. Slides only D. Only the HLD
**Q02 (O1)** A pack document without an owner, status, or date is: A. Fine if long B. Fine for operations C. Likely to become stale and untrusted D. Better for flexibility
**Q03 (O2)** What belongs in a decision log entry? A. Only the final choice B. Meeting minutes C. Source code D. Context, options considered, choice, consequences, owner, and date
**Q04 (O2)** How does an assumption differ from a decision? A. An assumption is believed but unverified, with an owner and date to confirm B. They are the same C. Assumptions are always wrong D. Decisions are unverified
**Q05 (O2)** Which risk entry is actionable? A. "Integration" B. "Security problems possible" C. "Because the ERP vendor releases monthly, stock API changes may break orders; owner, mitigation, review date given" D. "Be careful with vendors"
**Q06 (O2)** A risk register where entries have no owners or dates: A. Is complete B. Is a list of worries that drives no action C. Is better for morale D. Replaces assumptions
**Q07 (O3)** A good trigger for updating the HLD is: A. Every Friday B. Annual audit only C. When someone complains D. A significant design change or new ADR
**Q08 (O3)** Which approach keeps documentation current? A. Writing it all at the end B. A single author for everything C. Owners per document, update triggers, and reviews at phase boundaries D. Archiving it
**Q09 (O4)** How do you test whether the handover pack works? A. Count pages B. Have a newcomer answer typical questions using only the pack C. Ask the author D. Check the file sizes
**Q10 (O4)** A handover to operations should especially include: A. Marketing plans B. Sprint retrospectives C. Personal notes D. Deployment view, runbooks, monitoring, and open risks and decisions

## Answers
Q01 B · Q02 C · Q03 D · Q04 A · Q05 C · Q06 B · Q07 D · Q08 C · Q09 B · Q10 D

## Practical part
Pack review on the Larkspur lab: a pack structured by audience with decision log, assumptions, and risk register, plus the ten-question new-architect test. Pass: quiz at least 8/10, at least four of five exercises correct, and a lab pack from which the new architect answers all ten questions (gaps found are fixed and retested).
