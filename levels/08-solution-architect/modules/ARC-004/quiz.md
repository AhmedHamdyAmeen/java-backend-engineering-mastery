Outcomes: O1 TOGAF concepts · O2 viewpoints and views · O3 governance and compliance · O4 tailoring.

**Q02 (O1)** At the center of the ADM cycle is: A. Technology B. Migration Planning C. Governance D. Requirements Management
**Q03 (O1)** An architecture building block describes: A. The product chosen B. A server C. A required capability D. A test case
**Q04 (O1)** Gap analysis compares: A. Baseline and target B. Vendors and prices C. Teams and budgets D. Code and tests
**Q05 (O2)** In 42010 concepts, a viewpoint: A. Is a diagram of one system B. Is a stakeholder C. Is a risk D. Defines how to build views for a class of concerns

**Q09 (O4)** A sound tailoring rule is: A. Produce every artifact B. Use the same method for every program C. Hide the method from teams D. No artifact without a named consumer
