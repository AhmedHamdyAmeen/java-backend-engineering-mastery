# ARC-047 · AI vendor and model evaluation — Quiz

Outcomes: O1 vendor and model criteria · O2 evaluations beyond benchmarks · O3 AI proofs of concept · O4 multi-year cost and exit.

**Q01 (O1)** A provider scores highest on quality but its terms allow training on your prompts, against Larkspur policy. In the evaluation this is best treated as: A. A small deduction B. A gate failure unless the terms are changed C. Irrelevant to quality D. A pricing item
**Q02 (O1)** Which factor is easiest to overlook when comparing a self-hosted open-weight model with a hosted API? A. Model name B. Logo C. Operating effort: infrastructure, patching, monitoring, and skilled staff D. Documentation length
**Q03 (O1)** When should criteria weights be agreed? A. After scoring B. Before scoring, with stakeholders C. By the vendor D. Never
**Q04 (O2)** The best predictor of how a model will perform for Larkspur is: A. Its leaderboard rank B. Its marketing C. Parameter count D. Its results on an evaluation set built from Larkspur's own tasks
**Q05 (O2)** Which evaluation set is weakest? A. Fifty questions from real tickets, including out-of-scope and adversarial cases B. A set versioned and reviewed by two people C. Fifty easy questions that the knowledge base answers directly D. A set with rubrics and source documents
**Q06 (O2)** When a model or prompt version changes you should: A. Rerun the evaluation set and compare B. Assume equal quality C. Skip testing D. Update the leaderboard
**Q07 (O3)** A PoC should be time-boxed and judged against: A. Whether the demo looked good B. Votes from attendees C. Success criteria agreed beforehand on the riskiest questions, using realistic data D. Vendor claims
**Q08 (O3)** Which PoC test is most valuable? A. Ten toy questions B. Out-of-scope, conflicting-source, injection, and outage cases on realistic data C. A single happy path D. A logo review
**Q09 (O4)** Usage-based AI cost over three years is best modelled with: A. A fixed price per month B. The pilot month multiplied by 36 C. Conversations, cost per conversation, growth scenarios, other platform and people costs, and a switching reserve D. Vendor list price only
**Q10 (O4)** Which supports a credible exit plan? A. Prompts, evaluation sets, and data kept portable behind an abstraction layer, with contractual data return and deletion B. Deep use of proprietary features everywhere C. No documentation D. A long exclusive contract

## Answers
Q01 B · Q02 C · Q03 B · Q04 D · Q05 C · Q06 A · Q07 C · Q08 B · Q09 C · Q10 A

## Practical part
Evaluation report review on the Larkspur lab: criteria and weights, task-specific evaluation results for three approaches, terms review, three-year cost, and exit plan. Pass: quiz at least 8/10, at least four of five exercises correct, and a lab recommendation backed by evaluation scores, three-year cost, and an exit plan.
