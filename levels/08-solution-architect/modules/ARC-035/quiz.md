# ARC-035 · Architecture review boards — Quiz

Outcomes: O1 prepare a submission · O2 demonstrate compliance · O3 exceptions with mitigation and expiry · O4 conditions to closure.

**Q01 (O1)** The main purpose of an ARB is to: A. Write the design for the team B. Check fit with principles, standards, risk, and other projects C. Approve budgets only D. Select developers
**Q02 (O1)** Pre-wiring means: A. Installing network cables B. Sending the slides after the meeting C. Talking to board members beforehand to avoid surprises D. Skipping the session
**Q03 (O1)** A good submission starts with: A. The decision you ask the board to make B. The full code listing C. The vendor's brochure D. A list of team members
**Q04 (O2)** A credible compliance table has: A. Evidence links and honest statuses B. Only green statuses C. No evidence to stay short D. Only principles you comply with
**Q05 (O2)** Which is evidence for "no direct database access between systems"? A. A promise B. An ADR and an integration diagram showing interface-only access C. The team's opinion D. A project name
**Q06 (O3)** A design exception request must include: A. Only the standard name B. A request to ignore the standard C. A vendor quote D. Reason, risk, mitigation, owner, and expiry
**Q07 (O3)** An exception without an expiry date: A. Is preferred B. Becomes permanent by default C. Is invalid for security only D. Is automatically cancelled
**Q08 (O4)** The ARB grants conditional approval. You should: A. Ignore the conditions B. Close the ticket C. Track each condition with owner, date, and evidence D. Resubmit from scratch
**Q09 (O4)** Which behavior damages trust with the board? A. Reporting condition progress B. Ignoring conditions after approval C. Asking for clarification D. Pre-wiring members
**Q10 (O3)** Larkspur must use a file transfer interface to ERP until its upgrade. The best mitigation entry is: A. "Accept the risk" with nothing else B. Delete the standard C. Monitored encrypted transfer with reconciliation, an owner, and an expiry tied to the ERP upgrade D. Postpone the project

## Answers
Q01 B · Q02 C · Q03 A · Q04 A · Q05 B · Q06 D · Q07 B · Q08 C · Q09 B · Q10 C

## Practical part
ARB simulation on the Larkspur lab: submission, one exception, role-played board challenges, and a condition tracker. Pass: quiz at least 8/10, at least four of five exercises correct, and a simulation ending in approval or conditional approval with a closure plan.
