# JNR-035 · Security fundamentals — Quiz

Outcomes: O1 CIA and attacker goals · O2 trust boundaries · O3 least privilege and defense in depth · O4 Shop threat list.

**Q01 (O1)** Confidentiality means: A. Data is never deleted B. Only authorized people can read data C. The system is always up D. Data is backed up
**Q02 (O1)** A DDoS attack mainly targets: A. Confidentiality B. Integrity C. Non-repudiation D. Availability
**Q03 (O1)** A changed order total in transit breaks: A. Integrity B. Availability C. Confidentiality D. Authentication
**Q04 (O2)** A trust boundary is: A. A firewall brand B. A line where trust level changes C. A database table D. A type of encryption
**Q05 (O2)** Input from your own mobile app should be: A. Trusted B. Trusted if HTTPS C. Validated like any other input D. Ignored
**Q06 (O3)** Least privilege means: A. Everyone is admin B. Only the access needed to do the job C. No logins D. Shared passwords
**Q07 (O3)** Defense in depth means: A. One strong check B. Several independent layers C. Hiding the API D. Longer passwords only
**Q08 (O4)** Which is an asset of the Shop API? A. A request header B. Customer order data C. A controller class D. A port number
**Q09 (O4)** `GET /orders/{id}` is best described as: A. An asset B. An entry point C. A control D. A threat actor
**Q10 (O4)** A threat list entry should include: A. A planned control B. The developer's name only C. A logo D. Nothing else

## Answers
Q01 B · Q02 D · Q03 A · Q04 B · Q05 C · Q06 B · Q07 B · Q08 B · Q09 B · Q10 A

## Practical part
The lab threat list is reviewed against the assessment. Pass: at least 8 of 10 threats with sensible controls and a diagram that shows boundaries correctly; quiz 8 of 10.
