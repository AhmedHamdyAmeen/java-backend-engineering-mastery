# JNR-005 · Design patterns introduction — Quiz

Outcomes: O1 implement the patterns · O2 problem and choice · O3 patterns in JDK and Spring · O4 avoid needless patterns.

**Q01 (O1)** A factory method: A. Deletes objects B. Creates the right object for the caller C. Stores data D. Logs errors
**Q02 (O1)** A Decorator implements: A. A different interface B. No interface C. The same interface as the wrapped object D. A database
**Q03 (O2)** Which pattern removes an `if/else` that chooses an algorithm? A. Observer B. Repository C. Adapter D. Strategy
**Q04 (O2)** Which pattern fits a third-party API with a different shape? A. Adapter B. Builder C. Observer D. Factory
**Q05 (O2)** Many optional constructor parameters suggest: A. Observer B. Builder C. Decorator D. Repository
**Q06 (O2)** "Notify email and stock when an order is placed" suggests: A. Adapter B. Builder C. Strategy D. Observer
**Q07 (O3)** `Comparator` passed to `sort` is an example of: A. Strategy B. Observer C. Repository D. Builder
**Q08 (O3)** `BufferedReader` wrapping a `Reader` is an example of: A. Factory B. Adapter C. Decorator D. Observer
**Q09 (O4)** A Builder for an object with two fields is: A. Required B. Usually needless C. A security rule D. Faster
**Q10 (O4)** Which statement is right? A. Use as many patterns as possible B. Patterns are libraries C. Never use patterns D. Use a pattern only when it solves a real problem

## Answers
Q01 B · Q02 C · Q03 D · Q04 A · Q05 B · Q06 D · Q07 A · Q08 C · Q09 B · Q10 D

Eight exercises `JNR-005-EX01` to `EX08` plus the lab, with the scenario quiz (which pattern and why) as the written assessment. Pass: at least 8 of 10 quiz answers, seven exercises correct, and a README that justifies each lab pattern.
